taking an ssh of private instance through public instance 
## How it works

- Acts as a gateway: A jump server sits in a security zone and provides a single point of entry to a different, more protected zone.
- Segregates networks: It allows remote administrators to connect to internal devices that are not directly accessible from the internet.
- Secures access: By controlling all traffic through this single point, security measures like logging, auditing, and access control can be applied more effectively.
